## 一、项目概述

**Xinglin.ReportPlatform（杏林报告平台）** 是一个基于**契约驱动（Contract-Driven）** 架构的医疗报告单生成平台。通过将模板设计与数据生产解耦，实现医疗报告单的在线编辑、版本管理和多源数据适配生成。

### 核心工作流

```
模板设计 (Editor Web)  →  契约导出 (JSON)  →  数据录入 (ReportDataMaker WPF)  →  报告输出 (PDF)
```

## 四、核心架构

### 4.1 契约驱动架构

```
                    ┌──────────────────────────────────┐
                    │      Contracts (契约层)           │
                    │  元素模型 + 适配器接口 + 模板定义    │
                    └──────────┬───────────┬───────────┘
                               │           │
                    ┌──────────▼───┐  ┌───▼──────────┐
                    │ Editor (Web) │  │ Generators    │
                    │ 模板设计/管理  │  │ 数据生产/输出  │
                    └──────────────┘  └──────────────┘
```

Contracts 是整个平台的**单一数据源 (Single Source of Truth)**：
- 定义所有共享的类型、接口和枚举
- Editor 和 Generators 均引用 Contracts，确保两端对模板的理解一致
- 模板通过 JSON 序列化在两端之间传递

### 4.2 元素模型体系

```
ElementBase (抽象基类)
├── Id, X, Y, Width, Height       # 布局属性
├── Rotation, ZIndex               # 变换属性
├── Tooltip, IsLocked              # 交互属性
│
└── ExternalElementBase (外部元素基类，支持数据绑定)
    ├── Label, DataPath             # 数据绑定属性
    ├── IsRequired, Group           # 校验与分组
    ├── AdapterId                   # 关联适配器
    │
    ├── TextElement        ├── NumberElement
    ├── LineElement        ├── DateElement
    ├── TableElement       ├── DropdownElement
    ├── ShapeElement       ├── CheckboxElement
    ├── DividerElement     ├── RadioElement
    ├── BarcodeElement     ├── ImageElement
    ├── QrCodeElement      ├── IconElement
    ├── SignatureElement   ├── HyperlinkElement
    ├── ContainerElement   ├── ChartElement
    ├── RepeatElement      ├── FooterElement
    ├── HeaderElement      ├── PageNumberElement
    └── WatermarkElement
```

**元素分组机制 (ElementGroup)**：
- **Fixed** — 固定元素，无数据绑定
- **Context** — 上下文元素，DataPath 以 `Context.` 开头
- **Editable** — 可编辑元素，有 DataPath 但无适配器
- **DataAdapter** — 适配器元素，关联数据适配器

**功能分组 (ElementAdaptationGroup)**：
- **Basic** — Line, Divider, Shape
- **Form** — Text, Number, Date, Dropdown, Checkbox, Radio
- **Data** — Table, Repeat, Chart
- **Advanced** — Image, Barcode, QrCode, Signature, Hyperlink, Icon, Container, Header, Footer, PageNumber, Watermark

### 4.3 多态序列化

通过 `ElementJsonConverter` (基于 Newtonsoft.Json) 实现：
- 使用 `$type` 鉴别符（格式 `template.element.{shortType}`）
- 通过 `WebShortTypeMap` 映射短类型名到完整类型
- `TemplateSerializer` 封装统一序列化配置（CamelCase、忽略Null、枚举转字符串）

## 五、Editor 模块

### 5.1 数据层

| 实体 | 说明 | 关系 |

## 六、Generators 模块 (ReportDataMaker)

### 6.1 WPF MVVM 架构

```
ViewModelBase (INotifyPropertyChanged)
├── MainViewModel              # 主窗口：模板加载、适配器管理、标签页切换
├── SidePanelViewModel         # 侧边面板：展开/折叠
├── TemplateLoadViewModel      # 模板加载视图
└── TabViewModelBase (抽象)
    ├── MainTabViewModel           # 主标签页
    ├── DataEntryTabViewModel      # 数据录入标签页
    ├── PreviewTabViewModel        # 模板预览标签页
    ├── ExcelAdapterTabViewModel   # Excel 适配器标签页
    ├── DatabaseAdapterTabViewModel # 数据库适配器标签页
    ├── ContextAdapterTabViewModel  # 上下文适配器标签页
    └── ExportTabViewModel          # 导出标签页
Dialogs:
└── AddAdapterDialogViewModel  # 添加适配器对话框
```

### 6.2 标签页工作流

1. 加载模板 → 自动创建「数据录入」和「预览」标签页
2. 添加适配器 → 在预览标签前插入对应适配器标签页
3. 适配器读取数据 → 通过 `ApplyDataFromAdapter` 回填到数据录入页

### 6.3 Excel 适配器 —— 契约行模式

```mermaid
模板 → TemplateFlattenService → FieldSchema[] → ExcelSchemaExporter → .xlsx 模板
.xlsx (用户填写后) → ExcelContractReader → AdapterResult → DataBindingService → 填充模板
```

**Excel 文件结构（四行模式）**：
- 第1行（隐藏）：契约行 — 存储 `DataPath`
- 第2行：标签行 — 显示字段名称
- 第3行（隐藏）：类型行 — 数据类型与约束
- 第4行起：数据行

**核心组件**：`TemplateFlattenService`, `ExcelSchemaExporter`, `ExcelContractReader`, `ExcelDataValidator`

### 6.4 数据库适配器

支持 4 种数据库的统一查询接口：

```
DatabaseProviderRegistry → IDatabaseProvider
├── SqlServerProvider    (Microsoft.Data.SqlClient)
├── MySqlProvider        (MySqlConnector)
├── SqliteProvider       (Microsoft.Data.Sqlite)
└── PostgreSqlProvider   (Npgsql)
```

**两种查询模式**：
- **RawSQL** — 直接编写 SQL 语句
- **VisualBuilder** — 可视化构建（选择主表、列、WHERE、排序，自动生成 SQL）

**核心组件**：`DatabaseAdapterBase`, `DatabaseAdapterFactory`, `SqlBuilder`, `ConnectionPoolManager`

### 6.5 上下文适配器

自动填充医院/医生/日期等上下文字段：

```
ContextAdapterService → ContextAdapterFactory → ContextProfileStore
├── ContextAdapterConfig     # 适配器配置
└── ContextDataSource        # 上下文数据源
```

- 适配器执行链：Context → DataAdapter → Editable → 输出
- DataPath 以 `Context.` 开头的元素自动匹配

**核心组件**：`ContextAdapterService`, `ContextAdapterFactory`, `ContextProfileStore`, `ContextDataSource`

### 6.6 PDF 导出

基于 QuestPDF + SkiaSharp 的报告输出：

```
PdfExportService → PdfPageLayoutEngine → PdfElementRenderer
├── BatchExportService        # 批量报告生成
├── ReportDocumentPaginator   # 文档分页
└── ExportHistoryStore        # 导出历史记录
```

**核心组件**：`PdfExportService`, `BatchExportService`, `PdfPageLayoutEngine`, `PdfElementRenderer`, `ReportDocumentPaginator`, `ExportHistoryStore`

### 6.7 配置安全

- `AdapterConfigStore` — 适配器配置持久化到 `%AppData%/ReportDataMaker/adapters.json`
- `ConfigProtector` — 使用 **DPAPI** (Current User scope) 加密连接字符串，加密值以 `ENC:` 前缀标识
