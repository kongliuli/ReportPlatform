# ReportPlatform 项目总览与版本路线图

> 最后更新：2026-05-08
> 当前版本：v0.2.0（契约融合阶段）

---

## 1. 项目定位

Xinglin.ReportPlatform 是一个契约驱动的报告单生成平台，面向医疗机构的检验报告、病历、处方等结构化文档的设计、生产和管理。

**核心价值**：通过统一的模板契约，将报告单的「设计」与「生产」解耦，支持多种数据源适配和多种输出格式。

## 4. 版本路线图

### v0.3.0 — 架构统一（预计 2 周）

**主题**：将分散的模型和接口统一到 Contracts，建立清晰的依赖边界

- [ ] 将 ExternalElementBase 体系从 ReportDataMaker 移入 Contracts
- [ ] 将 IDataAdapter 接口（枚举化 AdapterType）移入 Contracts
- [ ] 将 ExternalElementConverter 移入 Contracts
- [ ] 定义 ElementGroup 四分体系（Fixed/Context/Editable/DataAdapter）
- [ ] 定义 ElementAdaptationGroup 枚举和 ElementGroupRegistry（23 种元素分 4 组）
- [ ] 实现 Context 适配器（配置文件 + 系统上下文自动填充）
- [ ] 实现 Fallback 适配机制（未知元素降级为 string）
- [ ] Editor.Core SharedInterfaces 对齐新的 Contracts 模型
- [ ] 清理 ReportDataMaker 中的 Legacy 模型代码

**交付物**：Contracts 成为唯一的模型定义来源，元素适配分组明确，向后兼容机制就绪

---

### v0.4.0 — WPF MVVM 重构 + HandyControl（预计 3 周）

**主题**：ReportDataMaker 架构升级，引入 HandyControl 美化，TabControl 驱动适配器页签

- [ ] 引入 HandyControl + DI 容器，配置主题
- [ ] 实现 IDialogService（基于 hc:Dialog）、AsyncRelayCommand
- [ ] 实现可折叠左面板（Expander 区域：模板信息/适配器列表/操作）
- [ ] 实现 TabControl 页签管理（每个适配器独立 Tab，可关闭）
- [ ] 重构 MainViewModel 为 Shell 编排器
- [ ] 重写 MainWindow.xaml（HandyControl 样式，隐式 DataTemplate 驱动 Tab 内容）
- [ ] 实现 TemplateLoadDialog（启动加载框，最近使用/浏览/服务器）
- [ ] 迁移 DataEntryWindow → DataEntryTab
- [ ] 迁移预览 → PreviewTab

**交付物**：标准 MVVM 架构，HandyControl 现代化 UI，模板加载 → Tab 页签切换 → 数据录入 → 导出的完整工作流

---

### v0.5.0 — Excel 适配器（预计 2 周）

**主题**：Excel 适配器作为小型适配工厂，基于扁平化契约驱动导入导出

- [ ] TemplateFlattenService：将 Editable 元素扁平化为单行 FlatField 列表
- [ ] ExcelSchemaExporter：导出带契约行（隐藏 DataPath 行）的 xlsx 模板
- [ ] ExcelContractReader：按契约行精确匹配导入数据（非列头文本匹配）
- [ ] ExcelAdapterTab 可视化配置面板（HandyControl StepBar 步骤指示）
- [ ] 数据类型校验（Number/Date/Dropdown 格式验证）
- [ ] 批量导入进度条和错误报告（hc:Growl 通知）
- [ ] 适配器配置持久化（.adapters.json）

**交付物**：用户导出 xlsx 模板 → 填写数据 → 按契约精确导入，支持单行和批量模式

## 6. 关键设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 模板存储格式 | JSON (ContentJson) | 灵活、可 diff、前后端通用 |
| 版本策略 | 全量快照 | 简单可靠，避免 patch 合并冲突 |
| 元素类型系统 | $type 多态反序列化 | 支持 20+ 元素类型的统一处理 |
| 适配器架构 | 枚举类型 + 接口 + 工厂 + 注册表 | 编译期类型安全，可插拔，新适配器零侵入 |
| 数据库适配 | Base + Provider 组件 | 通用逻辑复用，各数据库差异由 Provider 封装 |
| Excel 适配 | 扁平化契约工厂 | 导出 xlsx 即契约，导入按契约精确匹配 |
| WPF 架构 | MVVM + DI + HandyControl | 可测试，现代化 UI，TabControl 驱动页签 |
| 数据库 ORM | EF Core | .NET 生态标准，迁移方便 |
| 认证 | JWT + Refresh Token | 无状态，适合 API 场景 |
