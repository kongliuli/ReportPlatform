### 第四批修复（WPF 项目预存编译错误，0 ERROR + 42 WARNING）

**背景**：WPF ReportDataMaker 从 net10.0 改回 net8.0 后，暴露出约 100+ 个预存的编译错误。

#### 修复策略（按根因分类）
1. **类型层级不兼容（~40个错误）**：Contracts 库的 `TemplateDefinition.Elements` 为 `List<ElementBase>`，`Group`/`DefaultValue`/`IsRequired`/`AdapterId` 在 `ExternalElementBase` 上。部分元素类型（ContainerElement、HeaderElement、FooterElement、WatermarkElement、PageNumberElement、IconElement、LineElement、DividerElement、ShapeElement）不再继承 `ExternalElementBase`。
   - **解法**：将 `RenderElement`、`RenderPlaceholder`、`MakeTextBlock`、`RenderHeaderFooter`、`GetFontSize`、`ResolveValue`、`ApplyCanvasLayout`、`FlattenElement`、`AddField` 等方法的参数从 `ExternalElementBase` 改为 `ElementBase`；访问 `ExternalElementBase` 特有属性时添加 `element is ExternalElementBase eb ? eb.Group : ...` 安全访问。

2. **缺失类型/导入（~15个错误）**：
   - 创建 `FieldViewModel.cs`（FieldDataType/Options/TableCellData/IsMultiLine 等属性）
   - 添加 `ReadOnly` 到 `FieldDataType` 枚举
   - 添加 `using ReportDataMaker.Infrastructure;` 到 TemplateLoaderService.cs
   - 添加 `using System.IO;` 到 MainViewModel.cs、ExportTabViewModel.cs
   - 添加 `using Xinglin.ReportEditor.Contracts.Models.Adapters;` 到 FieldTemplateSelector.cs、FieldDataTemplateSelector.cs
   - 添加 `using System.Linq;` 到 CanvasRenderer.cs

3. **成员缺失/访问权限（~5个错误）**：
   - `MainViewModel._dataBindingService`/`_pdfExportService` → `internal readonly`
   - `MainViewModel.RefreshPreview()` → `internal void`（供 MainTabViewModel 调用）
   - `DatabaseAdapterTabViewModel.SelectedColumnNames` → 添加 `ObservableCollection<string>` 属性
   - `MainTabViewModel.RefreshPreview()` → 添加 `virtual` 方法
   - `TemplateDefinition.PageWidth/PageHeight` → `PageSettings.PageWidth/PageHeight`

4. **其他修复**：
   - `SignatureElement.Value` → `SignatureElement.SignatureData`（TemplateFlattenService.cs）
   - `TableCell.Label` → `TableCell.Text`（TemplateFlattenService.cs）
   - WatermarkElement `double?` FontSize 添加显式转换
