## 1. 顶层模板结构

```json
{
  "name": "模板名称",
  "type": "门诊",
  "version": 1,
  "pageWidth": 210,
  "pageHeight": 297,
  "orientation": "Portrait",
  "marginLeft": 15,
  "marginRight": 15,
  "marginTop": 15,
  "marginBottom": 15,
  "backgroundColor": "#FFFFFF",
  "globalFontSize": 12,
  "elements": [ ... ]
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 模板名称 |
| `type` | string | 是 | 类型：`门诊`、`住院`、`检验`、`处方`、`影像`、`护理` |
| `version` | int | 是 | 版本号，每次保存自增 |
| `pageWidth` | number(mm) | 是 | 页面宽度，A4=210 |
| `pageHeight` | number(mm) | 是 | 页面高度，A4=297 |
| `orientation` | string | 是 | `Portrait` / `Landscape` |
| `marginLeft/Right/Top/Bottom` | number(mm) | 是 | 页边距 |
| `backgroundColor` | string | 否 | 背景色，默认 `#FFFFFF` |
| `globalFontSize` | number(pt) | 否 | 全局字号，默认 12 |
| `elements` | array | 是 | 元素列表 |

| 复选框 | `template.element.checkbox` | input |
| 单选框 | `template.element.radio` | input |
| 下拉框 | `template.element.dropdown` | input |
| 数字 | `template.element.number` | input |
| 日期 | `template.element.date` | input |
| 表格 | `template.element.table` | data |
| 条形码 | `template.element.barcode` | data |
| 二维码 | `template.element.qrcode` | data |
| 图表 | `template.element.chart` | data |

## 3. 元素公共字段

所有元素共有的字段：

```json
{
  "$type": "template.element.text",
  "id": "el_xxx",
  "x": 10.5,
  "y": 20.0,
  "width": 80.0,
  "height": 15.0,
  "isVisible": true,
  "zIndex": 1,
  "backgroundColor": "transparent",
  "borderColor": "#000000",
  "borderWidth": 0,
  "borderStyle": "solid",
  "cornerRadius": 0,
  "opacity": 1.0,
  "fontFamily": "SimSun",
  "fontSize": 12,
  "fontWeight": "normal",
  "fontStyle": "normal",
  "foregroundColor": "#000000",
  "textAlignment": "left",
  "label": "姓名",
  "dataPath": "PatientName",
  "formatString": ""
}
```

| 字段 | 类型 | 单位 | 必填 | 说明 |
|------|------|------|------|------|
| `$type` | string | — | 是 | 类型标识，格式 `template.element.xxx` |
| `id` | string | — | 是 | 元素唯一标识 |
| `x`, `y` | number | mm | 是 | 左上角坐标 |
| `width`, `height` | number | mm | 是 | 元素尺寸 |
| `isVisible` | bool | — | **是** | 必须显式设为 `true`（C# bool 默认 false） |
| `zIndex` | int | — | 否 | 层叠顺序 |
| `label` | string | — | **是*** | 中文标签，可编辑元素必填 |
| `dataPath` | string | — | 否 | 数据绑定路径，驼峰格式 |

> \* `label` 字段：WPF 输入面板显示为 `姓名: [____]`，Canvas 渲染为 `姓名: 张三`。无 label 时 WPF 降级为显示 dataPath。

## 4. 序列化时剥离的字段

以下字段已确认 WPF 渲染器不使用，输出 JSON 时自动剔除：

| 字段 | 原因 |
|------|------|
| `rotation` | WPF 无旋转变换 |
| `shadow` | WPF 无阴影渲染 |
| `labelWidth` | WPF 不使用 |
| `isDataBound` | 纯元数据标记 |
| `richText` | WPF 仅纯文本 |
| `isRichText` | WPF 仅纯文本 |
| `minValue` | WPF 无校验 |
| `maxValue` | WPF 无校验 |
| `minDate` | WPF 无校验 |
| `maxDate` | WPF 无校验 |

## 5. 各元素类型专属字段

### 5.1 TextElement — 文本

```json
{
  "$type": "template.element.text",
  "text": "示例文本",
  "lineHeight": 1.5,
  "letterSpacing": 0
}
```

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `text` | string | `""` | 静态文本内容 |
| `lineHeight` | number | `1.5` | 行高倍数 |
| `letterSpacing` | number | `0` | 字间距（px） |

### 5.2 ImageElement — 图片

```json
{
  "$type": "template.element.image",
  "imagePath": "",
  "imageData": "",
  "stretch": "Uniform",
  "maintainAspectRatio": true
```

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|

## 6. 数据绑定

可编辑元素通过 `label` + `dataPath` 内联绑定：

```json
{
  "$type": "template.element.text",
  "label": "姓名",
  "dataPath": "PatientName",
  "isVisible": true
}
```

### 数据路径约定

| 路径 | 说明 |
|------|------|
| `PatientName` | 患者姓名 |
| `Gender` | 性别 |
| `Age` | 年龄 |
| `Department` | 科室 |
| `ReportDate` | 报告日期 |
| `ChiefComplaint` | 主诉 |
| `Diagnosis` | 诊断 |
| `Items[*].Result` | 检查项目结果 |

> 路径使用驼峰格式。WPF 通过 `dataPath` 直接查找数据源字段。

## 7. 坐标与字体

- 坐标单位：**mm**（渲染转换 `px = mm × 3.7795275591`）
- A4：210mm × 297mm
- 字体：中文推荐 `SimSun`（宋体）、`SimHei`（黑体）、`Microsoft YaHei`（微软雅黑）

## 8. 跨端兼容检查清单

- [ ] 所有元素 `$type` 使用 `template.element.xxx` 格式
- [ ] 可编辑元素包含非空 `label` 中文标签
- [ ] 所有元素显式 `"isVisible": true`
- [ ] `dataPath` 使用驼峰格式（如 `PatientName`）
- [ ] 坐标单位为 mm，范围 0~300
- [ ] 字体使用中文字体名
- [ ] 颜色格式 `#RRGGBB`

## 9. 变更对照 v2.1.0 → v2.2.0

| 变更项 | v2.1.0 | v2.2.0 |
|--------|--------|--------|
| $type 格式 | 双格式并存 | 统一 `template.element.*` |
| label | 可选 | 可编辑元素必填 |
| isVisible | 默认 true | 必须显式 `true` |
| 输出字段 | 全量输出 | 剥离 10 个冗余字段 |
| dataBindings 数组 | 独立声明 | 移除，改为内联绑定 |
| LabelInputBox | 支持 | 已废弃 |
