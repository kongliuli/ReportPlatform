# 患者信息录入与医疗评审系统使用方法说明

## 一、系统概述

本系统是一款用于患者信息录入和医疗评审的Windows应用程序，通过配置文件动态生成表单界面，支持自定义字段和模板管理。

## 二、configs目录结构

系统的配置文件存储在`MedicalFormApp\configs`目录下，采用JSON格式定义表单字段和数据结构：

```
configs/
├── medical_review_config.json  # 医疗评审信息配置文件
├── patient_info_config.json    # 患者信息配置文件  
└── temp/
    └── control.json            # 检验项目控制配置文件
```

### 1. patient_info_config.json

定义患者基本信息表单字段，包含以下内容：

```json
{
  "Fields": [
    {
      "FieldName": "PatientName",  // 字段名
      "Label": "患者姓名",        // 显示标签
      "Type": "text",             // 字段类型
      "Required": true,            // 是否必填
      "Placeholder": "请输入患者姓名"
    },
    {
      "FieldName": "PatientGender",
      "Label": "患者性别",
      "Type": "select",          // 下拉选择框类型
      "Options": ["男", "女"],  // 下拉选项
      "Required": true,
      "Placeholder": "请选择患者性别"
    },
    // 其他字段：年龄、ID、电话、出生日期等
  ]
}
```

### 2. medical_review_config.json

定义医疗评审相关字段配置，包含检验医生、评审信息等字段：

```json
{
  "Fields": [
    {
      "FieldName": "ExamDoctor",
      "Label": "检验医生",
      "Type": "text",
      "Required": true,
      "Placeholder": "请输入检验医生姓名"
    },
    {
      "FieldName": "ExamDate",
      "Label": "检验日期", 
      "Type": "date",           // 日期类型
      "Required": true,
      "Placeholder": "请选择检验日期"
    },
    // 其他字段：评审医生、评审日期、诊断结果等
  ]
}
```

### 3. control.json

定义检验项目的详细数据结构，包含列定义和数据行：

```json
{
  "columns": [
    {"name": "item_name", "label": "检验项目"},
    {"name": "reference", "label": "参考值"},
    {"name": "result", "label": "检验结果"},
    {"name": "unit", "label": "单位"}
  ],
  "rows": [
    {"item_name": "红细胞计数", "reference": "4.3-5.8×10^12/L", "result": "", "unit": "×10^12/L"},
    {"item_name": "血红蛋白", "reference": "130-175g/L", "result": "", "unit": "g/L"},
    // 更多检验项目...
  ],
  "infectiousDiseaseInfo": {
    "hepatitisB": {"name": "乙型肝炎表面抗原", "result": "", "unit": "ng/ml", "reference": "0-0.5"},
    // 其他传染病信息...
  }
}
```

## 三、界面功能说明

应用程序主界面分为以下几个主要区域：

### 1. 左侧树状结构

- 显示`configs`目录的文件结构
- 宽度为200像素，方便浏览配置文件
- 文件显示规则：
  - 特定文件(`patient_info_config.json`、`medical_review_config.json`)保持原名称
  - 其他JSON文件按目录顺序依次显示为"模板1"、"模板2"、"模板3"等

### 2. 右侧主内容区

主内容区包含两个Tab页：

#### (1) temp Tab页面

- 采用两列布局
- 左侧是StackPanel容器，包含三个动态生成的模块：
  - 患者信息模块(headContainer)：基于`patient_info_config.json`生成
  - 表单内容模块(controlContainer)：基于`control.json`生成
  - 医疗评审信息模块(footContainer)：基于`medical_review_config.json`生成

#### (2) 配置管理 Tab页面

用于编辑和管理配置文件内容，包含以下功能区域：

- **新模板名称输入**：输入新模板名称并保存
- **字段添加面板**：
  - 名称输入：设置字段名称
  - 必填设置：设置字段是否为必填项
  - 类型选择：支持文本、长文本、日期、下拉框四种类型
  - 下拉选项设置：当下拉框类型时可用，用逗号分隔选项
  - 添加字段按钮：添加新字段到配置中
- **数据表格切换**：包含两个子Tab页
  - 控件配置 (control.json)：编辑表单控件配置
  - 表头尾配置：编辑患者信息和医疗评审信息配置
- **操作按钮**：保存和取消配置修改

## 四、使用流程

### 1. 查看表单

1. 启动应用程序
2. 系统自动加载配置文件并在temp Tab页面生成表单
3. 左侧树状结构显示可用的配置文件

### 2. 编辑表单内容

1. 在temp Tab页面填写患者信息、检验结果和医疗评审信息
2. 各字段根据配置要求进行输入
3. 下拉选择框直接选择选项
4. 日期字段点击选择日期

### 3. 管理配置文件

1. 点击"配置管理"Tab
2. 选择要编辑的配置类型（控件配置或表头尾配置）
3. 在数据表格中编辑现有字段属性
4. 使用上方输入面板添加新字段
5. 完成编辑后点击"保存"按钮
6. 可选择"保存为新模板"创建新的配置文件

## 五、注意事项

1. 配置文件修改后需保存才能生效
2. 必填字段必须填写，否则表单可能无法正常提交
3. 下拉框选项需要使用英文逗号分隔
4. 系统支持的字段类型：文本、长文本、日期、下拉框
5. 配置文件必须符合JSON格式规范

以上就是本系统的使用方法说明，通过配置文件和界面功能的介绍，用户可以快速了解和使用该系统进行患者信息录入与医疗评审工作。
