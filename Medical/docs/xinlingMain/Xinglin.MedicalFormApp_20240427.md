# 医疗表单应用 (MedicalFormApp) 功能记录

## 应用概述
MedicalFormApp是一个基于WPF开发的医疗表单管理应用程序，主要用于配置和管理医疗表单模板，支持JSON树形结构的可视化编辑。

## 当前可完成的操作

### 1. 配置管理
- 创建新的表单配置模板
- 为新配置设置名称和基本属性
- 自动生成配置文件和相关目录结构

### 2. JSON树形结构编辑
- 加载和显示JSON配置的树形视图
- 支持不同类型的JSON节点（对象、数组、字符串、数字、布尔值等）
- 可视化编辑JSON节点的名称和值
- 在树形结构中添加、删除和修改节点

### 3. 表单生成与管理
- 基于配置生成医疗表单
- 管理表单字段（ConfigField类），包括字段名称、标签、类型等属性
- 处理表单中的选项文本（OptionsText）

### 4. 用户界面功能
- 多标签页界面设计
- 配置管理标签页，用于创建和管理表单配置
- 表单内容标签页，用于查看和编辑表单内容
- 医疗评审信息标签页

## 技术特点
- 使用Newtonsoft.Json库处理JSON数据
- 实现了CustomJsonTreeHelper类进行JSON与树形结构的转换
- 支持不同类型节点的模板选择器（CustomJsonNodeTemplateSelector）
- 实现了配置文件的目录管理和文件生成

## 注意事项
- 应用程序目前有一些空引用和null值转换的警告，但不影响基本功能运行
- 构建和运行均成功，退出码为0
- 表单配置文件保存在configs目录下
